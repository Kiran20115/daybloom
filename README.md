# 🌷 DayBloom — Personal Productivity & Study Studio

> A mindful, aesthetic productivity application built for students to manage daily schedules, track study goals, build healthy habits, and cultivate personal growth without overwhelm.

---

## ✨ Features

- **🌸 Personalized Dashboard**: Time-sensitive dynamic greeting, daily motivational quotes, circular progress indicator, priority focus tasks, and today's schedule.
- **✅ Smart To-Do List**: Categorized task management with priorities, due dates, subtasks, interactive completion celebrations with flower confetti, and overdue indicators.
- **⏳ Daily Planner & Timeline**: Hour-by-hour schedule (6 AM - 11 PM), current time marker, Day/Week view toggling, and Ivy Lee-inspired *"Plan My Day"* workflow.
- **📚 Study Tracker**: Pomodoro focus timer (customizable 25/5/15 intervals), subject mastery (DSA, DBMS, Web Development, Aptitude, Communication), and weekly study hours visualization.
- **🌱 Habit Sanctuary**: Weekly checkmark matrix, 90-day interactive consistency heatmap, habit streaks, and gentle non-guilt encouragement.
- **🎯 Goals & Milestones**: Short-term and long-term goal setting, milestone checkboxes, and real-time completion tracking.
- **📅 Interactive Calendar**: Month-by-month navigation, color-coded task categories, and quick date scheduling.
- **📊 Productivity Analytics**: Calculated completion rate, weekly trend bar chart, and category distribution pie chart via Recharts.
- **📝 Mindful Journal**: Tagged personal notes, pinned cheatsheets, and an evening **Daily Reflection** template capturing achievements, gratitude, and intentions.
- **🏆 Rewards & Badges**: Unlockable milestone achievements and celebratory confetti.
- **⚙️ Profile & Customization**: Name & avatar selection, Light/Dark mode, Pomodoro durations, and full JSON backup export & import.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS (Custom pastel lavender, blush pink, and cream palette)
- **Icons**: Lucide React
- **Charts**: Recharts
- **Celebrations**: Canvas Confetti
- **Storage**: LocalStorage with zero external trackers and JSON export/import

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/daybloom.git
   cd daybloom
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/`.

### Production Build

```bash
npm run build
npm run preview
```

## 🎨 Design Philosophy

DayBloom is inspired by the calm simplicity of Notion and Todoist combined with a pastel wellness planner. It uses soft lavender (`#EDE9FE`), blush pink (`#FDF2F8`), and warm cream (`#FAF7F2`) tones with dark mode support to ensure studying and planning feels peaceful, encouraging, and delightful.
